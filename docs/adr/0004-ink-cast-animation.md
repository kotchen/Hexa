# 起卦动画水墨显现与全应用纸感材质

2026-09-28 会话共识：现有「Timer 逐爻淡入」的起卦动画过于简陋，重做为一版水墨感显现动画，并将 AI 生成的宣纸材质提升为全应用背景。选择此方案是为了让"起卦"这一过程获得与"米白纸感、墨色卦爻、少量朱红"视觉语言一致的仪式感，同时保持 spec 已定的三条边界不被破坏。

## 规则

- 动画叙事演"卦象显现"，不引入铜钱等 spec 之外的道具；六爻自下而上，每爻以墨色线条从左到右生长，而非整段淡入。
- 总时长保持约三秒（上限 3.5s）：每爻约 400ms 一个周期（生长约 250ms + 停顿约 150ms），末爻落定后停留约 300ms 进入结果页。
- 变爻"先墨后朱"：以墨色落定，落定瞬间 200ms 内渐变为朱红，使"变"被直接演出。
- 每爻落定以线条轻微回弹作"视觉顿点"；不加声音、不加触感（Flutter 的 HapticFeedback 在 macOS 桌面端无效）。
- 跳过保留"跳过"按钮，且点击画面任意处均可跳过；跳过与播完进入同一结果页。
- AI 生成素材只承担氛围与材质：宣纸纹理为全应用通用背景；水墨底韵仅起卦页、以 multiply 混合约 10% 透明度叠于卦象后方。爻线一律代码绘制（CustomPainter），不使用贴图，保证六爻一致且生长进度可控。
- 素材置于 `app/assets/images/` 并在 pubspec 登记目录；纸纹压缩至约 2048px JPG，水墨底韵保留白底 PNG 以 multiply 消白。

## 后果与依据

动画仍仅展示，不参与起卦生成，与 ADR-0001"起卦结果不受动画播放或跳过影响"的后果一致；spec 的三条边界（仅展示、跳过同结果、不重复起卦）全部保持，spec 原文无需修改。

引入素材文件带来版权与体积管理责任：素材须确认生成来源可用、控制压缩体积，迭代时不得回退到六条各自手绘的爻线贴图（一致性由代码绘制保证）。纸纹全应用通用后，任何新页面默认继承纸感背景；结果页大段文字在纸纹上的可读性须逐页验证。

共识形成过程：用户确认方向（水墨感）、时长（约三秒）、素材边界（AI 生成两张氛围图）、反馈（视觉顿点替代触感）、跳过交互（按钮 + 全屏可点）、纸纹范围（全应用通用）。
