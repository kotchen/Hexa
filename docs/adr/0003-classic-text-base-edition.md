# 选定《周易》底本与逐字校核方法

用户已确认首版采用一个明确底本：通行本《周易》经文本（王弼注本系统，即阮元刻《十三经注疏》所收《周易正义》本之卦爻辞经文）。选择该底本是因为它是历代流传最广、异文最少的《周易》文本系统，便于初学者对照任何通行出版物，且与任务 01 已校核样例（乾、姤）的引用一致。

## 内容范围与呈现

- 范围：六十四卦卦辞、三百八十四爻爻辞、乾用九、坤用六。不含《彖》《象》《文言》《系辞》等传文。
- 呈现：简体（中国大陆通用规范汉字），标点保留底本句读。
- 繁简转换：OpenCC `t2s`；一对多字「乾」（易误转为「干」）及校核中发现的其余一对多字人工保护/复核，逐条记录。
- 异文处理：校勘异文（如否卦九五「包/苞」、同人九四「庸/墉」）不混入正文，正文取底本正字；差异如有底本系统内的实质异文，记录于 `.scratch/yi-app/content/` 校核报告中。
- 卦序：通行本（文王序）第 1–64 卦，与领域代码 `HexagramMap` 的映射逐项核对。

## 校核方法（不得以现成研究报告充当内容库）

1. 由实施者凭对底本系统的掌握**独立转录**全部经文为应用内容库（`app/lib/src/content/`），不复制任何现成数据集。
2. 以维基文库《周易》分卦页所载通行本文本为独立对照源（程序化抓取、转简体：`.scratch/yi-app/content/fetch_reference.py`，产物 `reference-wikisource.json`）。
3. 程序化逐字比对独立转录与对照源（`.scratch/yi-app/content/verify_classic.py`）：卦名、卦序、卦辞、逐爻爻辞、用九用六全部一致才算通过；任何差异逐条人工复核定夺，直至差异清零或剩余差异均有明确记录。
4. 校核产物与报告存于 `.scratch/yi-app/content/`，作为内容版本（`contentVersion`）的依据；历史卦例保存解释快照，内容升级不得静默改写旧记录。

## 白话解释与行动参考

白话解释与一般行动参考为应用原创、另行编写与审校，不属于底本；任务 02 仅保留任务 01 已批准的乾（卦辞、初九）与姤（卦辞）三条样例解读，其余条目界面明确显示「解读尚未完成」，不用通用占位文案冒充。

## 后果

- 内容库随 `contentVersion` 版本化；卦例记录内容版本以便追溯。
- 若未来更换底本或修订异文取舍，须新增决策记录并保留旧版本内容供历史卦例解释。

校核结果记录于 `.scratch/yi-app/content/verification-report.md`。
