# 三钱法数字模拟与明确标注的简化取辞规则

用户已接受首版使用三钱法数字模拟，并参考《易学启蒙》的取辞框架；三爻变时同时展示本卦与变卦卦辞，不判主次，明确标为产品简化，不称完整复原朱熹占法。选择此方案是为了给初学者提供来源可追溯、可验证的解读依据，同时避免将尚未校核的传统图表主次规则作为确定算法实现。

## 规则

- 每枚钱币独立等概率取 2 或 3，每爻取三枚之和，连续生成六爻，自下而上存储。
- 6 为老阴、7 为少阳、8 为少阴、9 为老阳；仅 6、9 变，阴阳翻转得到变卦。
- 无变爻：取本卦卦辞。
- 一变爻：取本卦对应爻辞。
- 二变爻：取本卦两条对应爻辞，较高爻为主。
- 三变爻：并读本卦、变卦卦辞，不判主次；这是本应用明确标注的简化。
- 四变爻：取变卦中对应原来两条不变爻位置的爻辞，较低爻为主。
- 五变爻：取变卦中对应唯一不变爻位置的爻辞。
- 六变爻：乾取用九、坤取用六，其他取变卦卦辞。

## 后果与依据

起卦结果不受动画播放或跳过影响。规则需版本化，以便历史卦例能够解释其生成依据；修改规则不得静默改变旧记录。卦序映射、原文底本和内容校核仍须独立完成。
