# 07: 保存、回看和删除本机历史卦例

Status: done

Parent: ../spec.md

**What to build:** 完成从起卦自动保存到重启回看及确认删除的本机闭环。

**Blocked by:** 02

## Acceptance criteria

- [x] 保存问题、时间、原始六爻、卦象、取辞依据、原文与已有解读快照及版本；最终内容任务接入后沿用同一机制。
- [x] 历史使用持久存储，重启后可回看；内容更新不重算或改写旧快照。
- [x] 保存失败时保留当前结果并提示重试；同一卦例重试不重复保存或重新起卦。
- [x] 支持历史空态、列表、详情、删除取消及确认；无账号、同步或导出。
- [x] 通过临时真实存储测试保存、重启读取、删除与失败重试，补充关键 UI 验证。

## 实施记录（2026-09-29）

### 存储选型（决策记录 [ADR-0005](../../docs/adr/0005-local-history-storage.md)）

- 小接口 `ReadingStore`（save/list/delete）延续任务 01–02 的注入边界：应用注入 `FileReadingStore`，测试注入 `InMemoryReadingStore` 或失败注入 `FlakyStore`；失败注入只经过存储接口，不依赖真实随机数或窗口时序。
- 本机实现：每条卦例一个 JSON 文件（以卦例 id 命名），存于 `~/Library/Application Support/yi_app/history`（macOS 沙盒把 HOME 重写到应用容器，数据只存本机）；先写临时文件再改名。无新增第三方依赖。
- 序列化：`dart:convert` JSON，完整保留快照字段（问题、时间、六爻原始数值、本卦/变卦与卦序、变爻位置、选中经文原文与白话/行动参考快照及主次、取辞依据、出处、起卦方法与规则依据、内容版本），带 schema 版本号；解码只还原字段，不按内容库重算，内容升级不改写旧快照。
- 卦例 id 起卦时由可注入 `IdSource` 生成（应用为随机源）；`HistoryController.save` 对已 saved 的 id 短路，存储层按 id 覆盖同文件——重试幂等：不重复记录、不重新起卦。保存失败置 `SaveStatus.failed`，结果由结果页保留在内存并明示「尚未保存到本机历史」+「重试保存」。
