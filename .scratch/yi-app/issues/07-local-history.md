# 07: 保存、回看和删除本机历史卦例

Status: ready-for-agent

Parent: ../spec.md

**What to build:** 完成从起卦自动保存到重启回看及确认删除的本机闭环。

**Blocked by:** 02

## Acceptance criteria

- [ ] 保存问题、时间、原始六爻、卦象、取辞依据、原文与已有解读快照及版本；最终内容任务接入后沿用同一机制。
- [ ] 历史使用持久存储，重启后可回看；内容更新不重算或改写旧快照。
- [ ] 保存失败时保留当前结果并提示重试；同一卦例重试不重复保存或重新起卦。
- [ ] 支持历史空态、列表、详情、删除取消及确认；无账号、同步或导出。
- [ ] 通过临时真实存储测试保存、重启读取、删除与失败重试，补充关键 UI 验证。

## Context

遵循首版规格、领域术语及已接受的规则与技术决策。此任务在独立会话实施前须阅读父规格；不得把未批准的新功能加入首版。
