**What to build:** 为文王卦序第 33–48 卦的每条可选原文提供完整白话解释和一般行动参考，并接入结果页阅读路径。

**Blocked by:** 02

## Acceptance criteria

- [x] 逐条覆盖这 16 卦的卦辞与六条爻辞。
- [x] 原创白话解释忠于对应原文；行动参考单列，不冒充原文或针对用户问题的个性化判断。
- [x] 每条解释关联已校核原文和出处，记录内容版本及审校结果；不得复制未获许可的现代译文。

- [x] 人工查看代表性长短文本在桌面窗口中的可读性；本任务只标记已完成范围，其余仍保留开发状态。

## 实施记录（2026-09-29）

### 内容编写与审校

- 覆盖范围：第 33–48 卦卦辞 16 条、爻辞 96 条，共 **112 条**，每条含白话解释（guaCiVernacular/yaoCiVernacular）与一般行动参考（对应 Action 字段），写入 `app/lib/src/content/classic_text.dart`。
- 全部为本项目原创编写：每条白话以「」直引对应已校核原文关键字句再作解释，忠于底本、逐条关联原文；未复制任何现成译文或网络解读。
- 行动参考与原文分列，统一以边界句收尾：「以上为应用提供的一般性行动参考，并非对未来的确定预测。」全部 112 条保留该边界表述，不冒充原文、不作个性化判断或确定预测。
- 语言面向零基础初学者，少术语、多直陈；同一卦六爻按爻位递进展开（如遁自「尾—革—系—好—嘉—肥」递退、明夷自「垂翼—伤股—南狩—入腹—箕子—晦极」、井自「泥—谷—渫—甃—冽—收」层层修治），自动测试断言同卦六条白话与行动参考两两互不相同，防止模板化。
- 第 44 卦姤卦辞为任务 01 已批准样例，属既有完成条目，本任务未改动该条一字，仅新编姤卦六爻解读；测试中显式标注该既有状态并断言其保持原批准内容。
- 经文底本未动一字（硬性要求）；仅新增解读字段。`GuaText` 结构与结果页 UI 未改：任务 02 已按条目渲染，缺省显示「解读尚未完成」。
- 内容版本号升级为 **classic-v1.3**（v1.2 基础上新增 33–48 卦已审校解读，经文与异文取舍未变）；出处引用沿用 `ClassicLibrary.sourceCitation`。
- 审校结果：原创作者自查（忠于原文、边界完整、递进不重复）+ 程序化逐条检查（关联原文关键字、边界句、同卦不重复、长度下限）+ 4096 穷举业务入口复验，全部通过。
