# 02: 真实起卦并显示有出处的完整原文

Status: ready-for-agent

Parent: ../spec.md

**What to build:** 用户输入问题后获得真实三钱法卦象与正确选取的原文、变爻及主次说明；固定解读仍在后续内容任务补齐。

**Blocked by:** 01

## Acceptance criteria

- [ ] 核实并记录一个明确底本，完成 64 卦、384 爻辞、用九用六的转录校核和卦序映射。
- [ ] 实现已批准的全部取辞规则，三爻变明确标注简化；一次起卦只生成一次，主动重新起卦才生成新卦例。
- [ ] 提供结果页来源与取辞依据，明确区分本卦概览和重点原文。
- [ ] 穷举 4096 种六爻输入及单爻 8 种组合，通过独立典型用例校验上下爻序、乾坤全变和多变爻。
- [ ] 缺少白话解释的内部开发结果明确显示未完成，不用通用占位文案冒充完整解读。

## Context

遵循首版规格、领域术语及已接受的规则与技术决策。此任务在独立会话实施前须阅读父规格；不得把未批准的新功能加入首版。
