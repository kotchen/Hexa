# 06: 完成第 49–64 卦的白话解读体验

Status: ready-for-agent

Parent: ../spec.md

**What to build:** 为文王卦序第 49–64 卦的每条可选原文提供完整白话解释和一般行动参考，并接入结果页阅读路径。

**Blocked by:** 02

## Acceptance criteria

- [ ] 逐条覆盖这 16 卦的卦辞与六条爻辞。
- [ ] 原创白话解释忠于对应原文；行动参考单列，不冒充原文或针对用户问题的个性化判断。
- [ ] 每条解释关联已校核原文和出处，记录内容版本及审校结果；不得复制未获许可的现代译文。
- [ ] 通过业务入口注入可控卦象，逐条验证选中内容能呈现且无缺项，覆盖跨本卦与变卦的引用。
- [ ] 人工查看代表性长短文本在桌面窗口中的可读性；本任务只标记已完成范围，其余仍保留开发状态。
