# 周易 App 需求访谈

状态：用户已确认整体方案、Flutter + Dart 技术选型与测试边界；进入规格与任务拆分。

## 已确定

- 主要用户完全不懂周易，希望在做事前算卦、解卦。
- 首版先由用户本人在 MacBook 上运行，交付可安装、独立打开的 Mac 桌面应用；明确不做浏览器应用。Windows、iPhone、Android 是后续平台目标。
- 用户先输入问题，然后进入起卦过程，解释围绕具体事件展开。
- 起卦时播放一段卦象动画，随后展开结果；不要求用户逐次模拟投币。
- 固定规则生成卦象及对应的《周易》原文。
- 解卦以通俗的处境解读和行动参考为主，并说明解释依据。
- 首版提供对应原文、预先编写的白话解释和一般性行动参考。
- 历史卦例自动保存在本机，包含问题、时间、卦象、原文及解读，支持回看与删除；首版不做账号、同步和导出。
- 界面采用简洁中式：米白纸感、墨色卦爻、少量朱红；动画约 3 秒且可跳过。
- 用户已接受“三钱法数字模拟＋明确标注简化处的取辞规则”：参考《易学启蒙》取辞框架，三爻变时并读本卦和变卦卦辞，不判主次。详见 docs/adr/0001-divination-reading-rules.md。

## 后续功能（首版不实现）

- AI 分析由独立按钮触发，结合用户问题进行白话解读。
- 用户配置 API Key 并选择模型后使用 AI 分析；服务商选择和连接设置延后讨论。

## 待明确

- 原文底本与逐字校核尚待完成，作为实施前内容准备任务。

## 已确认的工程与交互细节

- 问题不能为空；点击起卦后生成一次结果，动画期间防止重复提交。
- 跳过动画和回看历史都使用已有结果，不重新起卦；主动再次起卦生成新记录。
- 历史保存原文与解读快照，内容更新不改写旧卦例。
- 保存失败时保留当前结果并提示重试，重试保存不重新起卦。
- 删除单条历史前确认。
- 技术建议：Flutter + Dart，首版只启用 macOS 桌面目标。
- 测试建议：以“问题与可控的起卦输入 → 完整卦例 → 保存和回看”为主要业务测试边界；补充 4096 种六爻组合的规则验证，以及桌面安装启动和关键交互验证。
