# 周易桌面应用首版规格

Status: ready-for-agent

整体方案与测试边界已由用户确认。任务拆分尚待单独确认。

## Problem Statement

完全不懂周易的用户，希望在做事前围绕具体问题起卦，并读懂有原文依据的处境解释与行动参考。首版由用户本人在 MacBook 上使用，必须能安装并独立启动。

## Solution

交付离线可用的 macOS 桌面应用。用户输入问题，应用按三钱法数字模拟生成卦象，播放约三秒、可跳过的动画，随后呈现卦象、相关原文、预先编写的白话解释及一般性行动参考，并自动保存为可回看的本机卦例。采用米白纸感、墨色卦爻、少量朱红的简洁中式视觉。

## User Stories

1. 作为初学者，我希望安装后独立打开应用，以便无需浏览器或开发终端使用。
2. 作为使用者，我希望离线完成主要流程，以便不依赖网络或 AI 服务。
3. 作为使用者，我希望输入具体问题，以便记录本次起卦所关心的事情。
4. 作为使用者，我希望空问题得到明确提示，以便补充后再起卦。
5. 作为使用者，我希望点击一次即可完成起卦，以便无需学习投币步骤。
6. 作为使用者，我希望看到简短的卦象动画，以便理解流程正在推进。
7. 作为使用者，我希望跳过动画，以便直接阅读同一个结果。
8. 作为初学者，我希望看到本卦、变爻以及适用时的变卦，以便知道此次卦象如何变化。
9. 作为初学者，我希望阅读对应原文和白话解释，以便理解古文含义。
10. 作为使用者，我希望行动参考与原文区分展示，以便知道哪些是应用编写的建议。
11. 作为使用者，我希望看到本次取辞依据及来源，以便知道为什么重点阅读这些文字。
12. 作为使用者，我希望三爻变时明确说明简化读法，以便不误认为完整传统复原。
13. 作为使用者，我希望问题始终与结果关联，以便对照自己的处境阅读通用解释。
14. 作为使用者，我希望结果自动保存，以便以后回看。
15. 作为使用者，我希望重启应用后仍能找到历史，以便持续记录。
16. 作为使用者，我希望旧记录保持当时的解释，以便应用内容更新后仍可追溯。
17. 作为使用者，我希望确认后删除单条历史，以便管理本机记录。
18. 作为使用者，我希望保存失败时保留当前结果并可重试，以便不丢失本次卦象。
19. 作为使用者，我希望主动再次起卦产生新记录，以便与之前结果区分。
20. 作为使用者，我希望重复点击、跳过动画和历史回看不会意外重新起卦，以便结果稳定。

## Implementation Decisions

- 采用 Flutter + Dart，首版只启用 macOS 桌面，优先适配用户当前 Apple Silicon MacBook。后续平台复用作为结构目标，不要求本轮验证其他平台。
- 以生成、保存和读取完整卦例作为主要业务接口；界面调用业务能力，随机来源、存储及内容查询通过小接口替换，避免测试依赖真实随机数和窗口时序。
- 三钱法每枚独立等概率取 2 或 3，三枚之和为一爻，六爻自下而上。6/7/8/9 分别为老阴、少阳、少阴、老阳；只有 6、9 翻转形成变卦。卦序使用核对后的映射。
- 取辞遵循已接受规则：零变取本卦卦辞；一变取本卦该爻辞；二变取本卦两爻辞、较高为主；三变并读两卦卦辞、不判主次且标注简化；四变取变卦中对应两条原不变爻的爻辞、较低为主；五变取变卦中对应唯一原不变爻的爻辞；六变乾取用九、坤取用六，其余取变卦卦辞。
- 起卦生成一次结果，动画仅展示。提交期间阻止重复生成，跳过动画不改变卦例；主动再次起卦才生成新卦例。
- 内容至少覆盖六十四卦卦辞、三百八十四条爻辞、用九和用六，并为每条可被取辞规则选中的文字提供白话解释及一般行动参考。采用一个明确底本，记录出处、定位、版本和必要的繁简转换；具体底本由内容校核任务核实后记录。
- 白话解释及行动参考自行编写、人工或独立审校，分别展示，不冒充原文或逐字翻译。固定解读是通用解释，不声称理解用户问题或生成个性化预测。
- 卦例包含唯一标识、问题、时间、六爻原始数值、本卦与变卦、变爻位置、选中经文及主次、原文/解读/建议快照、算法及取辞和内容版本。存储技术由实施根据本机持久化需求选择。
- 自动保存且重试幂等；保存失败保留内存结果、说明尚未保存并允许重试。重启、内容升级及历史回看不重新随机或静默改写旧解释。
- 历史支持列表、详情及确认后删除；数据只保存在本机。需要有空列表及读写失败提示。
- 成品提供可复制安装的应用及简短安装说明，在开发终端关闭后仍能从 Finder 独立启动。公开分发、商店上架与相应签名发布流程不在首版范围。

## Testing Decisions

- 测试外部行为：以“输入问题及可控起卦输入 → 完整卦例 → 保存 → 回看”为主要业务边界，使用真实本机临时存储验证持久化。
- 枚举单爻八种钱币组合，验证四值计数为 1、3、3、1；不以随机抽样频率作为易波动的通过条件。
- 穷举四态六爻共 4096 种输入，验证变爻、卦象映射、取辞位置及所需内容完整。规则的典型预期来自独立人工用例，避免只重复实现。
- 固定用例包括全七乾、全八坤、全九取用九、全六取用六、乾初爻变为姤、坤初爻变为复，以及二、三、四、五变时的主次及位置。
- 内容检查覆盖所有条目的出处和解释、唯一 ID、爻序及映射。自动检查不能代替逐字校核和解释质量审查。
- 交互验证包含空问题、重复提交、跳过动画、保存失败重试、重启回看、删除取消及确认，检查结果不变和记录不重复。
- 最终检查 release 桌面构建、安装、脱离终端独立启动、离线主流程及米白/墨色/朱红布局可读性。
- 当前无应用代码及既有测试；首个实施任务建立最小测试入口。

## Out of Scope

- 浏览器应用及首版 Windows、iOS、Android 交付。
- AI 分析、API Key、服务商连接和模型选择界面。
- 账号、云同步、导出、公开商店上架。
- 完整复原蓍草操作、完整朱熹三变主次图表，以及多流派切换。
- 将固定解读包装成针对问题的智能判断或确定预测。
